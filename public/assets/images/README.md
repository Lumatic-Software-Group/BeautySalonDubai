Image Assets Directory

This directory contains optimized images for the beauty salon website.

Asset Guidelines:
- Photos: WebP format preferred, JPG fallback
- Icons: SVG format for scalability
- Hero images: 1920x1080px minimum resolution
- Service images: 800x600px recommended
- File size: Keep under 500KB for optimal performance

Color Scheme:
- Primary Gold: #D4AF37
- Rose Gold: #E8B4A0
- Background: #F8F6F0
- Text: #2C2C2C

Image Optimization:
- Compress all images before deployment
- Use appropriate alt text for accessibility
- Implement lazy loading for better performance
