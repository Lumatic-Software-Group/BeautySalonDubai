## Image Optimization Guidelines

### File Formats
- **Photos**: WebP (primary), JPG (fallback)
- **Icons**: SVG (preferred), PNG (fallback)
- **Graphics**: PNG with transparency

### Sizing Standards
- **Hero Images**: 1920x1080px, 1440x900px, 1200x800px (responsive)
- **Service Images**: 800x600px, 400x300px (responsive)
- **Icons**: 64x64px, 32x32px, 24x24px (multiple sizes)

### Performance
- **Compression**: 80-85% quality for JPG
- **WebP**: 75-80% quality
- **File Size**: <500KB for large images, <50KB for service images

## Implementation Notes

### HTML Integration
- Use `<img>` tags with `alt` attributes for accessibility
- Implement lazy loading with `loading="lazy"`
- Provide WebP with JPG fallbacks

### CSS Integration
- Use CSS `background-image` for decorative images
- Implement responsive images with `srcset`
- Use CSS sprites for small icons when appropriate

### Performance
- Compress all images before upload
- Use appropriate image formats
- Implement progressive loading for better UX
